Privacy

Last updated 26 October 2026

Handwriting Lab is a demo run by Koo Haoming, an individual in Singapore. It has no accounts, no cookies and no analytics.

Your drawing

When you lift your pen or press Guess, your browser shrinks the drawing to a 28 by 28 pixel greyscale image and sends only that image to the server. The server uses it to make one prediction and then discards it. Drawings are not saved, and they are not used to train the model.

Connection data

  • To stop abuse, the server counts requests per IP address for 60 seconds. The count lives in memory and is not written to disk.
  • The server writes ordinary request logs (time, page requested, response status), which can include an IP address.
  • The site is hosted on Railway and served through Cloudflare. Both process connection data, such as your IP address, to deliver the page, under their own privacy policies.

Fonts and third parties

The font is served from this site. The page loads no third-party scripts.
